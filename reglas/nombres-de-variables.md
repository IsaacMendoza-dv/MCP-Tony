# Nombres de variables

Esta regla define cómo nombrar variables, funciones y constantes en el código.

## Principios

- Usa nombres descriptivos que expliquen la intención, no el tipo.
- Evita abreviaturas ambiguas: escribe `cantidad_usuarios` y no `cant_usr`.
- No uses nombres de una sola letra, salvo índices de bucles cortos (`i`, `j`).

## Convenciones

- Variables y funciones: `snake_case` en Python y `camelCase` en JavaScript.
- Clases: `PascalCase`.
- Constantes: `MAYUSCULAS_CON_GUION_BAJO`.
- Las variables booleanas empiezan con `es_`, `tiene_` o `puede_`.

## Ejemplos

- Correcto: `fecha_de_creación`, `tiene_permisos`, `TOTAL_MÁXIMO`.
- Incorrecto: `d`, `data2`, `flag`.
